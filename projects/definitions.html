Internet

Internet is the network that connects computers all over the world.

Web

Web is service that lets people see web pages.

How are the Internet and Web different?

The internet is the road and the web is just one of the cars that uses it.

ASCII and Unicode

ASCII only knows English letters but Unicode knows all languages and symbols.

What is UTF-8

UTF-8 helps Unicode save storage more efficiently on computers.

URL

It is the full address used to find a specific page on the web.

Domain Name

Humans cannot memorize IP addresses easily, so domain names are created to replace them with simple names like google.com.

HTTP

It sends information between web browsers and servers without security.

HTTPS

It is a secure version of HTTP that protects and locks data.

IP address

It is a unique number address given to each computer on a network.

DNS

It simply converts domain names into IP addresses for computers to understand.

W3C Recommendations

They are rules and standards recommended by W3C for web developers.

XML, XHTML, HTML, HTML5

XML holds data, HTML builds web pages, XHTML is just a strict HTML and HTML5 is the modern version that plays videos.
