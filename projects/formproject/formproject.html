AJAX Questions

1. What is AJAX?

AJAX is a way to get data from a server without refreshing the whole page. It make websites faster and easier to use.

2. Why do you put your JS code in a separate file?

I put my JavaScript in a separate file because it is more organized. It is also easier to find and change my code.

3. How do you use the inspector (DevTools) to debug your JavaScript? How do you find the line number of an error?

I press F12 to open DevTools. Then I go to Console to see if I have any errors. I can click the error and see which line has the problem.

4. Do your form and fields have the same IDs that your JavaScript uses? Does the Console show any errors? List your IDs, and fix any errors before you submit.

Yes, my IDs match with my JavaScript. My IDs are signup-form, name, email, password, gender, yes, no, music, basketball, soccer, about, birthday, age, and response. My form is working and it shows "You have signed up". I checked the Console and there are no errors.
