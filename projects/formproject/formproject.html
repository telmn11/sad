JavaScript Questions

1. What is JavaScript? How did it get its name?

JavaScript is a programming language used to make websites interactive. It was first called LiveScript, but later its name was changed to JavaScript.

2. What are the two ways you can run JavaScript?

You can run JavaScript inside a web browser or using Node.js.

3. What is jQuery? Is it still popular today?

jQuery is a JavaScript library that makes coding easier. It is still used today, but it is less popular than before.

4. What is the most popular front-end JS library today?

React is one of the most popular front-end JavaScript libraries.

5. How does your code prevent the form from being submitted? Why do we need to prevent it?

The code uses event.preventDefault() to stop the normal form submission. This prevents the page from reloading.
