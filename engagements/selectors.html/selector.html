1. List out the different ways to select an item.

We can select an item by tag name, ID, class, or children.

2. What is the difference between an ID and a Class?

ID is for one element and class can be used for many elements.

3. What is the difference between a SPAN tag and a DIV tag?

A span is for a small part of text and div is for group things.

4. What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

A div is a general container. Header, main, and footer have different purposes.

5. What are the different ways to select a color?

We can use color names, HEX, RGB, or HSL.
