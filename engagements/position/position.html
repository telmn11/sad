Positioning

CSS helps us arrange pictures and text on a web page. We can use different positioning properties.

Normal flow is the default layout of HTML elements. Block elements stack from top to bottom.

Float moves a figure to the left or right. Text can wrap around the figure.

Float and Clear

The clear property makes a heading start below a floated figure. This prevents the heading from appearing beside the figure.

Relative Position

Relative positioning moves an element from its original position. The original space remains on the page.

Absolute Position

Absolute positioning removes an element from normal flow. We can move it using top, bottom, left, and right.

Fixed Position

Fixed positioning keeps an element in the same place on the screen when we scroll.

Questions

1. What is normal flow in HTML?
Normal flow is the default layout of HTML elements. Block elements stack from top to bottom.

2. What does float do? Why do you need to clear the float?
Float moves an element to the left or right, allowing text to wrap around it. Clear makes the next element start below the floated element.

3. What do absolute, fixed, and relative do?
Relative moves an element from its original position. Absolute positions an element outside normal flow. Fixed keeps an element in the same place on the screen when scrolling.

4. How can you make nice navigation buttons for mobile devices?
We can use display: block, width: 100%, and padding to make large buttons that are easy to tap.
