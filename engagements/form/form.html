Questions

1. What does the action attribute do?

The action attribute tells the browser where to send the form information.

2. What does the method attribute do?

The method attribute tells the browser how to send the form information.

3. What is the difference between POST and GET?

GET sends information in the URL. POST sends information in the request body.

4. How do you fill in a form control with a pre-set value, and how is that different from a placeholder?

Text box: Use the value attribute.
Textarea: Put text between the textarea tags.
Select box: Use the selected attribute.
Checkbox: Use the checked attribute.
Radio button: Use the checked attribute.

A value is already entered in the form. A placeholder is just a hint that disappears when you type.

5. List all the form controls that HTML5 added. Which ones did you put in your form?

HTML5 added these input types: color, date, datetime-local, email, month, number, range, search, tel, time, url, and week.

I added email, date, and number to my form.
