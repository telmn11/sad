Questions

1. What is the main difference between CSS Grid and CSS Flex?

CSS Grid is used to arrange items in rows and columns. Flexbox is mainly used to arrange items in one direction, either a row or a column.

2. Who decides where a child goes on the page: the child or its parent?

The parent decides where its children go. In my grid, the parent div uses CSS Grid to arrange Box A through Box F into columns and rows.
