What I Learned

I learned how to use Flexbox to arrange items inside a parent. I can use display: flex, flex-wrap, gap, and justify-content to control the position of the items. Flexbox can arrange items in a row or a column.

Website Accessibility

An accessible website is a website that people with different abilities can use. It should have clear text, good color contrast, keyboard navigation, and descriptions for images. Accessibility helps more people use a website.
