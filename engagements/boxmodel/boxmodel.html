Questions

1. What is the difference between block and inline tags?

Block tags start on a new line. Inline tags stay in the same line as text.

2. What are margin, border, and padding?

Margin is space outside a box. Border is the line around a box. Padding is space between the content and the border.

3. What units can you use in CSS?

CSS units include px, %, em, rem, vw, and vh.

4. When would you use a figure tag?

I use a figure tag to group an image with a caption.
