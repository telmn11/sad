CSS

1. Explain the difference between inline, embedded, and external CSS?

Inline CSS is writing CSS code inside an HTML tag, like style="color: red;".

Embedded CSS is writing CSS code inside the HTML page using a style tag.

External CSS is writing CSS code in a separate CSS file.
