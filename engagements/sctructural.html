1. What goes in the header?

The header usually contains the title, logo, or introduction of a webpage.

2. What goes in the Nav?

The nav contains links that help users move to different pages or sections.

3. Can the Nav go in the header?

Yes, the nav can go inside the header.

4. Does the Nav have to be in the header?

No, the nav does not have to be inside the header.

5. Does the Nav contain links to another website?

It can contain links to another website, but it can also contain links to pages on the same website.

6. What goes in Main?

The main contains the most important content of the webpage.

7. What goes in the Footer?

The footer usually contains copyright, contact information, or other additional information.

8. What is HTML Validation?

HTML validation checks if the HTML code is written correctly and follows HTML rules.
